Milesight (formerly Ursalink) makes indoor and outdoor LoRaWAN® gateways for industrial and smart-building deployments, with Ethernet, Wi-Fi and cellular backhaul. The gateways run a web interface for configuration and support both LoRa Basics™ Station and the Semtech UDP Packet Forwarder.
